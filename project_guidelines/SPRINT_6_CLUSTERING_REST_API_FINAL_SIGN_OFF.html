Day 36

KMeans Clustering

  • Write src/analytics/clustering.py implementing KMeans clustering with 5 clusters
  • Features to use: return_on_equity_pct, debt_to_equity, revenue_cagr_5yr, fcf_cagr_5yr, operating_profit_margin_pct
  • Before scaling: impute missing values with sector median for each metric
  • Apply StandardScaler to normalise all features to zero mean and unit variance
  • Run KMeans with n_clusters=5, random_state=42 — for reproducibility
  • Generate elbow plot (inertia vs k from 2 to 10) — save as reports/elbow_plot.png — confirm k=5 is near the elbow
  • Generate output/cluster_labels.csv with columns: company_id, cluster_id (0-4), cluster_name, distance_from_centroid

Cluster Profiling & Statistics

  • Review cluster names with team lead — adjust based on which actual companies are in each cluster
  • Generate correlation matrix heatmap: Pearson correlation of 10 KPIs across all 92 companies for latest year — save as reports/correlation_heatmap.png using seaborn heatmap with annotation
  • Outlier detection: compute Z-score for each metric per broad_sector — flag companies where any metric has absolute Z-score > 3 — save to output/outlier_report.csv
  • Generate output/portfolio_stats.csv with P10, P25, P50, P75, P90, Mean, Std for each KPI across all 92 companies

Day 39

API Endpoints — Company Data

  • GET /api/v1/companies — return list of all 92 companies with id, company_name, broad_sector, sub_sector, roe_pct, roce_pct — support optional filter parameters: sector, market_cap_category, search
  • GET /api/v1/companies/{ticker} — return full company profile: all companies fields + latest year KPIs + sector data — return HTTP 404 if ticker not found
  • GET /api/v1/companies/{ticker}/pl — return P&L history array — support from_year and to_year query params
  • GET /api/v1/companies/{ticker}/bs — return balance sheet history array — same year filter params
  • GET /api/v1/companies/{ticker}/cashflow — return cash flow history array — same year filter params
  • GET /api/v1/companies/{ticker}/ratios — return all computed KPIs per year for the company
  • GET /api/v1/companies/{ticker}/tearsheet — return the pre-generated tearsheet PDF as a binary file download
Day 40

API Endpoints — Screener, Sector, Peer & Remaining

  • GET /api/v1/screener — screener endpoint with query params: min_roe, max_de, min_fcf, sector, min_rev_cagr_5yr, min_pat_cagr_5yr, max_pe — return ranked company list
  • GET /api/v1/sectors — return all 11 sectors with company_count, median_roe, median_pe, median_de
  • GET /api/v1/sectors/{sector}/companies — return all companies in a sector with latest year KPIs
  • GET /api/v1/peers/{group_name} — return all companies in a peer group with percentile rank for each of 10 metrics
  • GET /api/v1/companies/{ticker}/peers/compare — return radar data: 8 axis metric values for the company + peer group average + benchmark company
  • GET /api/v1/market-cap/{ticker} — return historical valuation multiples
  • GET /api/v1/portfolio/stats — return P10 through P90 percentile table for 10 core KPIs across all 92 companies
  • GET /api/v1/companies/{ticker}/documents — return annual report links with is_url_valid boolean flag
  • Export OpenAPI spec: save docs/openapi.json — export Postman collection JSON
